Privacy

Your notes stay under your control

JotKeep works without an account. The application keeps your notebook in this browser and does not send note content to JotKeep or an analytics service.

Last reviewed: 11 August 2026

What stays in browser storage

JotKeep stores your notes, note titles, timestamps, active-note selection, list preferences, restore points, backup status, and a bounded recovery journal on this device. Notebook data and history use IndexedDB. Appearance settings, the recovery journal, and your remembered choice to dismiss the first-use guide use local storage.

The browser controls this storage. Clearing site data, resetting the browser profile, or removing the browser can erase it. Browser storage is not an external backup.

When JotKeep uses a file you select

JotKeep reads a local file only after you select it to open, test, or restore. It cannot browse other files on your device. A text file is read to create a note. A JSON backup or Safety File is read and validated before JotKeep offers to change the notebook.

If you connect a Safety File and grant file access, JotKeep writes the current notebook and restore points to that file after local saves. It reads the file back after each write to verify it. You can disconnect the file at any time. Disconnecting JotKeep does not delete the file.

If direct file access is unavailable, JotKeep prepares a browser download instead. Your browser controls where that download is saved.

How to remove local JotKeep data

In JotKeep, select File, then Clear all local data…. After you confirm, JotKeep removes notes, history, preferences, backup status, recovery data, and its remembered Safety File connection from browser storage.

To also remove cached application files and site permissions, clear the site data for the JotKeep origin in your browser settings. Downloaded backups, text files, and Safety Files are outside browser storage and are not deleted by either removal method.

Cookies, analytics, and network requests

The JotKeep application code does not set or read cookies. It does not include analytics, advertising, crash reporting, telemetry, or third-party application resources. It makes no automatic requests to third-party origins.

The browser requests the application, icon, fonts, and updates from the same JotKeep origin. These requests do not include your note content. Like other websites, the hosting provider receives standard request details, such as the IP address, date, and browser headers, when it sends these files. JotKeep does not automatically send your notebook to an external service.

Privacy questions

Ask a privacy question or report an incorrect statement in the JotKeep issue tracker. Issues are public, so do not include note content, a backup, or other private information. Following this link opens GitHub, whose own privacy terms apply.
