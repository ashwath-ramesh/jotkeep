    Three things to know before you write

    This guide closes after your first edit, or you can close it now.

    1. 01

      Write in private plain text

      JotKeep is a private, plain-text notepad. No account is required.

    2. 02

      Know where notes are kept

      Notes save to browser storage on this device. Browser storage is not an external backup and can be cleared.

    3. 03

      Keep an external copy

      Use a Safety File or export a JSON backup from the File options.

            Use Safety File replaces the local notes,

            Overwrite the Safety File?
          
    
          
    
          
    
            The file's current notes, preferences, and history will be
            replaced with the local notebook and local history. JotKeep will
            read the file back before it reports Backed up.
